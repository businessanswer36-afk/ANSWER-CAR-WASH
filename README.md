# Answer Car Wash — hébergement
1. Supabase: créer un projet puis exécuter `supabase_schema.sql` dans SQL Editor.
2. GitHub: envoyer tous les fichiers dans le dépôt `answer-car-wash`.
3. Render: créer un Web Service, Runtime Node, Build `npm install`, Start `npm start`.
4. Variables Render: `SUPABASE_URL` et `SUPABASE_SERVICE_ROLE_KEY`.
5. Render donnera une adresse Internet à ouvrir sur PC et téléphone.
Compte de démonstration: admin / 1234.
IMPORTANT: la Service Role Key est secrète et ne doit jamais être mise dans le navigateur ou publiée sur GitHub. Cette base doit encore recevoir une authentification serveur complète avant usage commercial.
